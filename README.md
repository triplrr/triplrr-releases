# Triplrr downloads

Android APKs for [Triplrr](https://triplrr.com), the offline travel memory app.

**Download the latest version:** https://triplrr.com

Each release attaches `triplrr.apk`. To install it, allow "Install unknown apps" for your browser when Android asks. Questions: support@triplrr.com

The app source code is not public; this repository only hosts release files.
